# Security policy

## Reporting a vulnerability

Please use this repository's private vulnerability-reporting feature. If it is
not available, do not include vulnerability details in a public issue; open a
minimal issue requesting a private reporting channel instead.

Reports receive a best-effort response. No service-level agreement or bounty is
offered.

## Scope

Security issues in these personal-infrastructure Terraform modules are in scope,
including unsafe defaults, privilege escalation, and unintended exposure of
Cloudflare resources. Deployment-specific configuration and credentials are out
of scope.
